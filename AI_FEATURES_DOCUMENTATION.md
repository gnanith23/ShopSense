# 🤖 ShopSense — AI Features Documentation

> **What AI features are in ShopSense, what technologies power them, and which files are involved — all in one place.**

---

## 📌 Overview

ShopSense uses **Generative AI** to help vendors automatically write product descriptions, generate SEO keywords, create product tags, and evaluate catalog health — all without leaving the dashboard.

---

## 🧠 AI Model & API

| Item | Detail |
|------|--------|
| **AI Provider** | [OpenRouter](https://openrouter.ai) — a unified API gateway for multiple AI models |
| **Model Used** | `openai/gpt-oss-20b:free` (accessed through OpenRouter) |
| **API Endpoint** | `https://openrouter.ai/api/v1/chat/completions` |
| **Auth** | Bearer Token via `OPENROUTER_API_KEY` environment variable |
| **Response Format** | JSON (`response_format: { type: "json_object" }`) |
| **HTTP Client** | `axios` (npm package) |

> **Note:** The file is named `geminiService.js` for historical reasons, but it currently calls the OpenRouter API (not Google Gemini directly). The `@google/genai` and `@google/generative-ai` packages are installed in `package.json` but the active implementation uses OpenRouter.

## 🔥 Feature Breakdown

---

### 1. ✨ AI Content Generation (Core Feature)

**What it does:** Vendor enters a product name and category → clicks **"✨ Generate AI Content"** → AI automatically writes:
- A professional product **description**
- 3 **AI Tags** (for discoverability)
- 3 **SEO Keywords** (for search ranking)

**How it works (data flow):**

```
AddProduct.jsx (Frontend)
  → POST /api/ai/generate-product-content  { productName, category }
  → aiRoutes.js
  → aiController.js
  → geminiService.js
  → OpenRouter API (model: openai/gpt-oss-20b:free)
  ← JSON { description, aiTags[], seoKeywords[] }
  ← aiController.js (parses + sanitizes JSON)
  ← AddProduct.jsx (fills form fields)
```

**Prompt sent to AI:**
```
Generate a professional e-commerce product description.

Product Name: {productName}
Category: {category}

Return ONLY valid JSON.
{
  "description": "...",
  "aiTags": ["tag1", "tag2", "tag3"],
  "seoKeywords": ["keyword1", "keyword2", "keyword3"]
}
```

**Key files:**
- `backend/services/geminiService.js` — builds prompt, calls OpenRouter
- `backend/controllers/aiController.js` — handles request/response, strips markdown fences
- `backend/routes/aiRoutes.js` — `POST /api/ai/generate-product-content`
- `frontend/src/pages/vendor/AddProduct.jsx` — UI trigger button + state management

---

### 2. 📊 AI SEO Score Card

**What it does:** After AI generates content, an **SEO Score Card** appears (score 0–100) showing:
- ✅/❌ Evaluation of title, description length, category, AI tags, SEO keywords
- 💡 Actionable improvement suggestions

**How the score is calculated (frontend only — no API call):**

| Check | Points |
|-------|--------|
| Product title > 5 characters | +20 |
| Description > 20 words | +20 |
| Category provided | +20 |
| AI Tags present | +20 |
| SEO Keywords present | +20 |
| **Total** | **100** |

Score color: 🟢 ≥80 (green) · 🟡 ≥50 (yellow) · 🔴 <50 (red)

**Key file:** `frontend/src/components/AiseoScoreCard.jsx`

---

### 3. 🤖 AI Assistant Panel (Dashboard)

**What it does:** A smart panel on the **Vendor Dashboard** that analyzes the vendor's entire product catalog and surfaces priority action items:

| Rule | Trigger | Color |
|------|---------|-------|
| Missing product images | Any product has no `imageUrl` | 🔴 Red |
| Out of stock | Any product has `stock === 0` | 🔴 Red |
| Low stock alert | Any product has `stock < 5` | 🟡 Orange |
| Missing AI content | Products without `aiTags` or `seoKeywords` | 🟢 Green |
| Zero sales | Catalog has 0 total sales | 🔵 Blue |

**How it works:** Purely **client-side logic** — no API call. Uses `useMemo()` to evaluate all products in memory.

**Key file:** `frontend/src/components/AIAssistantPanel.jsx`

---

### 4. 📈 AI Catalog Insights Widget (Dashboard)

**What it does:** Shows a 5-metric grid on the dashboard:

| Metric | Logic |
|--------|-------|
| Total AI Generated | Count of products with `aiTags` or `seoKeywords` |
| Missing Description | Products with descriptions < 10 words |
| Missing SEO | Products without `aiTags` and `seoKeywords` |
| Missing Images | Products without `imageUrl` |
| Marketplace Ready | Products with description + AI + image + stock > 0 |

**How it works:** Purely **client-side logic** using `useMemo()` over the product array.

**Key file:** `frontend/src/components/AIInsightsWidget.jsx`

---

### 5. 🎯 Catalog Quality Score (Dashboard)

**What it does:** Shows a circular progress meter (0–100%) representing the average optimization score across all products.

**How each product is scored:**

| Item | Points |
|------|--------|
| Description > 20 words | +20 |
| Has image URL | +20 |
| Has AI Tags | +20 |
| Has SEO Keywords | +20 |
| Stock > 0 | +20 |
| **Per product total** | **100** |

**Overall score:** `sum of all product scores / number of products`

**How it works:** Purely **client-side logic** using SVG circle animation.

**Key file:** `frontend/src/components/CatalogQualityScore.jsx`

## 🗄️ Database Schema — AI Fields

In `backend/models/Product.js`, every product document has these AI-specific fields:

```js
// AI-Generated Tags (from OpenRouter API)
aiTags: {
  type: [String],
  default: []
}

// SEO Keywords (from OpenRouter API)
seoKeywords: {
  type: [String],
  default: []
}
```

These are saved when the vendor submits the Add/Edit Product form after clicking "Generate AI Content".
